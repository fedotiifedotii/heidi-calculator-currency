# ✨ Хайди Калькулятор + Конвертер валют

Лёгкий калькулятор с конвертером валют и криптовалют на **Python + Tkinter**.

Живые курсы через:
- [frankfurter.dev](https://www.frankfurter.app/) — фиатные валюты
- [Coinbase](https://www.coinbase.com/) — криптовалюты + RUB / KZT / UAH

## Возможности

### Калькулятор
- `+ − × ÷`
- Процент `%`
- Смена знака `±`
- Очистка и backspace

### Конвертер
**Фиат:** USD, EUR, RUB, CNY, GBP, JPY, KZT, UAH  
**Крипта:** BTC, ETH, USDT, BNB, SOL, XRP, TON, DOGE

## Запуск

```bash
pip install requests
python calculator_currency.py
```

Требуется Python 3 с поддержкой `tkinter` (обычно уже установлен).
